Features

一个控制面，管住所有设备上的 Agent

从用户、设备到会话与审批，闭环都在控制面完成；执行面只负责跑。

多用户、多设备

一个 Worker 就是一台设备。桌面、云端、手机共享同一份会话，身份与配额按用户隔离。

Multi-user · multi-device

Computer / Sandbox

Computer 关机保留镜像，Sandbox 挂载目录继续用。按任务选择持久化方式。

Two device forms

人在回路

工具审批、批量允许/拒绝、多问题提问，全部走同一套通道，拒绝会作为工具错误回给模型。

Human-in-the-loop

本地模型

Ollama 开箱即用，也支持 LM Studio、llama.cpp 等任意 OpenAI 兼容端点。

Ollama · OpenAI-compatible

自托管

Docker Compose 或 Kustomize 一条命令起全栈。数据、密钥、模型都不出你的环境。

Docker · Kubernetes

可观测

Prometheus 指标、审计日志、会话级事件流。断线自动重连，删除与关机都有补偿。

Metrics · audit · SSE
Architecture

控制面与执行面分离

客户端只发 HTTP + SSE；工具调用永远发生在 Worker 内，网关负责把请求安全地送进隧道。

Quick start

五分钟，在自己机器上跑起来

只需要 Docker。默认使用本地 Ollama 或任意一个模型 provider。

# 1. 克隆并准备环境
git clone https://github.com/getsounder/sounder.git
cd sounder
cp .env.example .env

# 2. 填模型：云端 key 或本地 Ollama
#   MODEL=ollama/qwen2.5:3b
#   OLLAMA_HOST=http://host.docker.internal:11434/v1

# 3. 起全栈
make up
open http://localhost:3000
1
用 Docker Compose 启动 8 个服务Web · API · Gateway · Worker · Postgres · Redis · MinIO
2
注册账号，或使用 -auth=false 的单租户本地模式OAuth、邮箱密码、设备配额、审计都内置
3
新建设备，打开会话，发第一条指令需要审批的工具会出现在聊天里，等你点允许
4
需要时切到云端 Worker同一份会话，桌面关机也能继续
